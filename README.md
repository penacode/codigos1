# 💻 Projetos do Curso de HTML e CSS

Este repositório reúne todos os projetos desenvolvidos durante meu aprendizado de HTML e CSS. Cada projeto representa um novo conceito aprendido e aplicado na prática, com foco em estruturação semântica, estilização responsiva e boas práticas de desenvolvimento web.

---

## 📁 Estrutura dos Projetos

Cada pasta representa um projeto diferente abordado no curso. Alguns dos tópicos explorados:

- Estrutura básica de páginas HTML
- Hierarquia de títulos e semântica
- Inserção de imagens e links
- Listas ordenadas e não ordenadas
- Estilização com CSS externo, interno e inline
- Classes, IDs e seletores CSS
- Box Model (margin, padding, border)
- Layouts com `flexbox` e `grid`
- Responsividade e media queries
